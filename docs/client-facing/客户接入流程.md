# 客户接入流程 SOP

## 阶段一：咨询接洽 (0-1天)

1. 客户通过邮件/飞书发起咨询
2. 24小时内回复，了解基本需求
3. 判断是否在服务范围内
4. 安排 30 分钟线上沟通

### 初次沟通 Checklist

- [ ] 客户背景与行业
- [ ] 要解决的具体问题
- [ ] 期望的交付形式
- [ ] 预算范围
- [ ] 时间预期
- [ ] 技术环境 (已有系统/平台)
- [ ] 决策人 & 对接人

## 阶段二：方案报价 (1-3天)

1. 出具技术方案文档
2. 提供报价单 (见报价模板)
3. 跟进确认

## 阶段三：签约启动

1. 双方确认方案与报价
2. 签订合作合同
3. 客户支付首款 (如分期)
4. 拉项目群，建立沟通渠道
5. 分配 Git 仓库 (clients/{客户项目名})

## 阶段四：开发交付

1. 按项目计划推进开发
2. 每周交付进度同步
3. 验收测试
4. 交付尾款
5. 交付源码与文档

## 阶段五：售后维护

- 交付后 1 个月免费维护 (Bug 修复)
- 后续按维护合同或按需计费
